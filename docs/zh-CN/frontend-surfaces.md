# 前台、工作空间后台与系统后台

## 1. 目的

HaloAI 将面向团队的协作体验、工作空间治理和平台运营明确拆成三个界面区域。拆分首先服务于心智模型和最小权限，而不是为了制造更多页面。

| 区域         | 稳定路由   | 使用者                                        | 核心职责                                             |
| ------------ | ---------- | --------------------------------------------- | ---------------------------------------------------- |
| 协作前台     | `/app`     | 团队成员与受邀访客                            | 房间、消息、文档、AI 协作、审批和成果交付            |
| 工作空间后台 | `/admin/*` | Workspace Owner、Workspace Admin 与专项管理员 | 成员、角色、AI、集成、安全、用量与审计               |
| 系统后台     | `/system`  | 平台运营与安全人员                            | 租户生命周期、系统健康和全局策略，不默认读取租户内容 |

根路由 `/` 只负责进入协作前台，不承载第二份首页。

## 2. 导航与视觉边界

- 协作前台围绕房间、对话和文档组织，保持沉浸式工作台布局。
- 工作空间后台使用独立管理外壳，固定显示当前工作空间、访问角色和配置影响范围。
- 两个区域共享品牌令牌、主题和语言偏好，但不共享页面层级和主要导航。
- 桌面后台采用侧边导航与内容画布；窄屏将导航转换为可横向浏览的分区栏，禁止压缩为不可读的小型桌面页。
- 前后台之间使用明确的文本入口返回，避免仅使用含义模糊的图标。

## 3. 授权边界

1. `/admin/*` 的每次请求都必须由服务端依据当前会话、工作空间成员状态和 Capability 决定是否放行。
2. 客户端隐藏菜单、保存的主题或语言、URL 参数和本地存储都不是授权证据。
3. 工作空间管理总览要求 `workspace.manage`；安全策略要求 `workspace.security.manage`；审计要求 `audit.read`。
4. 直接访问无权页面时显示不泄露资源细节的拒绝状态，并提供返回协作前台的路径。
5. `/system` 使用独立的平台身份与授权域，禁止把 Workspace Owner 自动提升为系统管理员。
6. 系统人员访问租户内容必须经过限时、具理由、可审计的 Break-glass 流程。

## 4. 当前 Alpha 边界

当前实现提供完整可导航的协作前台与工作空间后台界面骨架。本地开发环境由服务端注入受控的 Owner 预览身份，用于设计和浏览器验收；生产构建在真实认证接入前默认拒绝后台访问。

后台当前展示可验证的示例状态，操作按钮只执行本地界面反馈，不代表已经修改持久数据。任何尚未连接 API 的动作必须明确说明状态，不得产生成功写入的假象。

系统后台当前只提供受限入口与安全边界说明，不提供租户数据或模拟运营操作。

### 4.1 非 AI 协作外壳

在聊天编排、模型供应商和 Agent Run 正式接入前，协作前台先补齐可独立验收的团队工作路径：

- 工作空间总览聚合最近房间、待处理事项和共享文档，并明确展示负责人与状态。
- 收件箱支持在提及、待审批和邀请之间切换；未连接 API 时只允许本地标记已读，不宣称持久化成功。
- 文档目录支持搜索、状态筛选和返回所属房间的文档面板。
- 活动记录只展示可归因的人员、时间和对象，不展示或暗示 AI 的隐藏推理。
- 上述页面不得触发模型调用、工具调用或外部写入，并持续显示本地预览边界。

视觉层级继续使用 HaloAI 的语义令牌。参考产品只用于校准信息架构、留白和交互密度，不复制其品牌、配色或 AI 权限模型。

## 5. 完成标准

- `/app`、`/admin/overview` 和各后台分区可通过真实链接互相导航。
- 后台桌面与 390px 移动视口无非预期水平溢出，交互目标不小于 44×44 CSS 像素。
- 中文、英文与明暗主题覆盖协作前台、后台和拒绝状态。
- 无权主体不能通过直接输入 URL 绕过服务端守卫。
- 每个后台页面显示当前作用域，并区分已生效、待审批、未连接和只读状态。
- 系统后台默认拒绝 Workspace 角色，且不展示租户内容摘要。
- 总览、收件箱、文档目录和活动记录可从协作前台真实切换，且不触发 AI 或外部写入。
- 1440×900 保持房间、对话、文档三栏；平板和移动端转换为单视图路径，不依赖压缩桌面布局。
