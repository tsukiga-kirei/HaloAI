# HaloAI 交付路线

> 当前进度：阶段 0 已形成可运行框架；阶段 1 已完成 PostgreSQL schema、首个迁移、租户事务与项目/房间/消息 repository，真实认证和 HTTP 数据链路仍待接入。

## 阶段 0——规格与基础

- 完整的中英文产品、UX、领域、安全与架构规格。
- 产品级响应式导航和视觉系统。
- 类型化领域模型、权限策略和 Agent 契约。
- 中英文消息目录与主题 token。
- 演示对话与共享文档体验。
- 仓库级开发约束和质量门槛。

## 阶段 1——可用的内部 Alpha

- PostgreSQL repository 与 migration（基础已完成，继续扩展身份、文档与运行 repository）。
- 认证、工作空间邀请和项目成员关系。
- 真实房间、消息和文档 API。
- 一个可配置模型供应商和流式输出。
- Agent 创建、提及路由、运行预算和审计时间线。
- 本地文档版本与人工审批流程。

## 阶段 2——团队 Beta

- WebSocket presence 与可靠消息投递。
- 基于 Yjs 的协同编辑、评论和建议模式。
- 耐久任务队列、重试、取消和恢复。
- 受治理的知识来源和权限感知检索。
- 模型密钥库、路由、成本面板和使用限额。
- PWA 安装、推送通知与离线草稿。

## 阶段 3——受控执行

- MCP 注册表和每个 Agent 独立工具白名单。
- 隔离的 TypeScript Worker 与受限网络出口。
- 外部和不可逆行为审批收件箱。
- 签名 Webhook、集成身份和不可篡改审计导出。
- SSO、SCIM、保留、法律冻结与企业部署配置。

## 成功指标

- 从创建房间到产生第一份被接受成果的时间。
- AI 建议被采纳或编辑进入最终文档的比例。
- 在纠错率不升高的前提下节省的人工审阅时间。
- 每条被接受贡献的成本与延迟。
- 被拒绝或升级审批的风险行为，以及策略误报率。
